# 太空任务执行层验证与边界

## 实现内容

- 主机启动下一开拓阶段，机器一次一项，同队同天体开拓互斥，跨队独立；矿机一轮一次且不占天体开拓锁。
- 启动前校验结构、主世界、红石、绑定主机、固定归属、阶段、方案、资源选择、实际输入和输出容量；无足够当前输出空间不扣料。
- 扣料按组件约束匹配，原子全有或全无。托管保存实际投入的所有额外组件，reload退款精确返还。
- 主机只按方案512/2048/8192 EU/t耗电，取消旧2048基础耗电；矿机独立供电，组装模块保留原配方。
- 输入托管、任务时间/功率/产物快照、进度、剩余交付都在机器区块NBT；任务索引仅保存位置、锁、加载范围和reload纪元，不保存第二份物品。
- 每足额支付一次功率推进一tick，无电或红石禁用保留进度；用户手动暂停释放任务票。自动模式关闭只阻止下一轮，当前轮可完成。
- 有效任务强加载本机结构；矿机还加载绑定主机及结构。使用独立类型ticket，不改玩家强制加载集。完成、退款、手动暂停、拆机释放票；缺电暂停保留。
- 正常重启恢复任务索引和快照，不按现实停机时长补进度。阶段完成即解锁，待交付物逐次减少，堵输出不耗电不启动下一轮。
- 成功reload取消未完成任务并关闭自动循环，实际投入留原机REFUNDING状态重试输入槽；已完成WAITING_OUTPUT不取消。失败目录不取消任务。持久化reload纪元处理暂未加载的机器。
- 扳手拆机在序列化掉落物前取消RUNNING并损失投入，完成/退款待交付随机器物品保存；普通破坏时完成/退款剩余物按库存掉落。在途投入不掉落。
- UI启动须等待配置ACK，防止点了新目标却发射旧选择；普通包不能自填进度、功率或奖励。公开NBT过滤任务托管与退款。
- mining方案严格4输入/6返回条目；开拓仍9/9。采矿资源与设备返回合并校验真实6输出槽容量，count不足5长程产生0。

## 已执行检查

- 原子库存/任务/解析：51项，包含重叠组件约束最大流分配、失败无扣料、额外组件、删除组件约束、物理容量、部分交付保存、完成/退款幂等、坏NBT拒绝、mining4/6和开拓9/9。
- 实际状态容器/索引生命周期：27项，包含扣料到完成、部分交付保存恢复、退款重入、自动标志、阶段回执、持久化故障锁、开拓锁作用域和索引纪元往返。
- 操作包：26项真实RegistryByteBuf编码检查；17项接线/本地化覆盖检查。客户端4类独立编译通过。
- 服务端与客户端Gradle编译通过；最终`spotlessApply build`成功，耗时45秒，最终JAR包含任务执行器、操作包和月球数据。

独立生命周期检查只模拟调用者的能量门控，没有调用实际MinecraftServer/ServerWorld执行器，不能视为真实区块票、红石、FTB联机或服务器异常断电测试。普通save/restart下，机器库存和任务一起保存保证部分交付不重领；跨多个世界存储文件的任意断电/磁盘损坏不是事务型数据库保证。阶段回执和同步保存用于降低索引/阶段与区块写入顺序风险。

## 实机验收

1. 成型主机选择月球T1，在输入放1个充油T1探测器，等待目标配置确认后点发射；应立即扣输入，512EU/t推进，6000tick完成并返回未充油T1。
2. 缺电期间进度不变；补电继续。红石停止亦不丢进度。暂停按钮释放加载票，恢复后重新获取。
3. 同队另一主机不能同时对月球开拓；其他天体可以。不同队伍彼此不阻塞。矿机同时采同一天体不互锁。
4. 用测试命令推进登陆/据点，成型同队矿机绑定主机，选择1到3资源、器材级别，存目标后启用自动。持续供应充油无人机，确认每轮精确返回干无人机和选定资源；输出占满等待，不重复扣料。
5. 基础月球有据点T1/T2/T3轮次1200/300/75tick；无据点6000/1500/375tick。缺材料/满输出启动失败以1Hz重试，不以1秒间隔拖慢正常连续轮次。
6. 当前轮运行时改目标/矿种，当前产物不变，下一轮使用新选择；关闭自动让当前轮完成后停止。
7. 运行时退出所有玩家并保持服务器tick，检查任务可继续；远方发电站未加载导致断电应暂停。重启世界后续跑，不退款、不补算离线现实时间。
8. 运行中成功/reload，原样退回输入，不发奖励不退电，自动关闭。把原输入槽填满再reload，退款留原机，清空槽后逐步退回；重开/重启不重复退。
9. 完成后堵输出，再reload：已完成奖励不变。普通破坏和扳手拆机分别验证在途投入丢失、完成/退款库存保留，不带在途任务移动继续跑。
10. 运行任务的目标、投入和退款不能通过周围玩家的普通区块NBT广播读取；跨队控制包和槽位操作被拒绝。

最终经济、注油配方和EMI尚未提供；测试数据材料不是正式平衡。现有旧存档矿机RecipeCrafter已移除；切换前已被旧配方消耗的在制投入没有可恢复托管快照，建议先结束旧配方再升级或由管理员处理旧在制任务。
