# 太空任务系统实施计划

## 已确认规则

- 原地改造太空电梯主机与采矿模块；组装模块保持原样。UI 继续继承 RebornCore，保留真实库存、红石、IO、能量和结构全息图。
- 每主机一项开拓；同队同天体开拓互斥；跨队互不阻塞。开拓不阻塞采矿模块。每模块一轮采矿，多模块允许同目标并行。
- 队伍共享测绘/登陆/据点进度，机器绑定队伍，任务启动时冻结归属。
- T1/T2/T3 方案功率 512/2048/8192 EU/t。开拓、采矿均允许高等级方案，耗时乘 0.25^(设备等级-任务等级)，不吃通用超频。
- 有据点为基准采矿时间与产量，无据点时间5倍、产出floor(count*0.2)。资源固定count，每次选定各产一次，最多3种。
- 设备精确inputs/outputs按阶段与设备等级声明，不自动替换。充油在精密组装机完成，具体燃料由整合包定义。
- 启动托管投入并冻结任务快照；完成即解锁，堵输出等待交付，不耗电、不开始下一轮。拆机取消未完成任务并损失投入，完成品按库存交付。
- 必要区块强加载，离线继续、缺电暂停。运行任务恢复与加载票生命周期需持久化。
- 天体 data/<namespace>/techreborn/planet/<path>.json；parent唯一决定轨道父子；system仅分组；marker取default blockstate的顶面；orbit_features为字符串数组。
- 恒星只展示，黑洞测绘后长程轨道采矿，不能登陆或建据点。

最新完整规则见 [完整实现规格](space-missions-spec.md)。下列第一阶段记录历史UI交付，第二阶段已接入真实服务端数据，第三阶段现已接入任务执行与自动采矿。

## 1. UI与器材（已完成）

- 共享星图：按星系切换、拖动平移、滚轮缩放、点击聚焦跟随、轨道线、marker顶面、卫星、环带、黑洞与迷雾/扫描视觉。
- 主机：左侧天体详情与阶段导航；上下九进九出真实槽位；中部星图；右侧现有同步模块列表。
- 采矿模块：共享星图、目标选择、可滚动资源池、最多三种选择与轮次预览；保留现有真实库存，旧生产逻辑本阶段仍保留，不将预览选择发送为生产命令。
- 仅客户端预览目录与视图状态；预览星体数值不是生产数据，不解锁队伍进度。任务按钮禁用并说明后端未接通。
- 注册三等级无人机/探测器/登陆舱的未充油与充油态，以及三个据点核心；充油模型layer0原图+layer1通用_powered覆盖。
- 中英本地化、原生配置页输入隔离、小屏幕适配、构建与人工布局检查。

## 2. 服务端数据与同步（本轮完成）

- 严格校验天体JSON、组件ItemStack、父节点存在/循环、方案等级、稳定资源ID、输出数量上限。原子reload，坏数据不得部分覆盖。
- 按可见性过滤的服务端星图快照，不把未解锁资源直接同步给客户端。
- 持久化队伍进度、机器固定归属与天体/方案/稳定资源选择；GUI配置包校验窗口、距离、机器所属队伍、结构与版本，禁止客户端授予进度。任务快照、库存托管和运行状态校验留给执行层。
- 原生槽位与红石/IO配置也执行归属校验。操作员命令用于测试阶段解锁，普通GUI无法推进阶段。
- 内置太阳/展示地球/月球/火星样例，月球与火星含显式T1/T2/T3方案；资源与材料为测试经济配置。
- 成功reload时在发布新目录前取消未完成任务并原样退款；退款仅留原机等待输入槽腾空，失败reload不取消任务。重启继续原快照，不当作reload。
- 将客户端演示目录替换为服务端视图适配器；按钮禁用原因来自服务端权威结果。

## 3. 执行与自动化（本轮完成，待实机验证）

- 主机真实开拓库存与任务执行、开拓互斥、阶段前置、任务恢复、拆机损失。
- 采矿模块移除旧即时配方处理，接入选定天体与资源的自动循环；目标更改仅下轮生效。
- TechReborn供电/红石/IO集成；主机无旧2048额外耗电，矿机独立供电；任务调度轮转。缺电保留进度和票，手动暂停/完成/拆机释放票。
- 任务和托管物保存于机器区块，位置索引恢复强加载与开拓互斥；输出待交付和退款逐项递减保存，完成回执恢复阶段。扳手拆机丢失未完成投入，保留已完成/退款待交付物。
- mining方案4输入/6返回，开拓9/9；启动前检查实际完整产出容量，当前空间不足不扣料。
- UI启动/自动循环开关/手动暂停恢复；关闭自动模式只停止后续轮，选择更改只影响下一轮，操作须等待服务端配置确认。

## 4. 兼容与视觉（已接入，待实机验收）

- EMI开拓每个天体一页，T1/T2/T3投入/返回/功率/耗时并列，可见阶段用页内标签切换，等级是替代方案。采矿页在测绘且资源可见后可查，未登陆仅提示执行前置；没有可见采矿方案时保留引导页。加入服务器、目录reload、阶段和队伍变化后更新，无需打开终端。旧矿机普通配方不再展示。
- Jade复用一般机器提示框，显示目标、阶段/状态、器材等级、所需/实际耗电、long tick与秒进度、实际托管输入、完整冻结产物和剩余交付/退款。外队不发送私有任务数据。
- 主机模块列表独立于配方/供电/结构登记，已加载模块40tick心跳；暂未加载模块标记保留，不为列表强加载。
- 器材方案下方显示数据包全部要求投入与数量，支持全部9项开拓/4项采矿，不猜测航天器家族。
- 星图航迹从地球出发，以出发/抵达天体的父节点公转切线构成简化转移弧，轨道坐标独立于窗口/缩放；跨星系页标明地球来源，不画虚构起点。真实任务目标括号/扫描环、完成/退款提示与机器附近粒子/声音由服务端事件驱动；反馈不影响业务结算。
- 完整天体范围、正式经济配置和精密组装机注油配方由整合包负责，不在Java硬编码材料、燃料或产量。GLSL增强不属于本轮。

## 验证边界

本阶段不启动服务端冒烟测试；通过编译、资源/布局核对验证。只有实机才能确认游戏字体、原生配置浮层与鼠标在不同GUI缩放下的最终效果；静态稿不冒充游戏截图。
