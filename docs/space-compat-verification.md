# 太空模块展示、EMI/Jade与任务反馈

## 本轮改动

### 模块列表

旧逻辑仅在矿机任务或组装机配方校验时向主机登记；因此已绑定但空闲、缺料或结构未成型的模块可能缺席。

矿机与组装机现在独立以40tick心跳登记已加载的绑定主机，不依赖配方、供电或结构。主机验证模块类型、实际绑定、主世界与128格平面距离，仍保持最多8模块。暂时卸载的模块保留登记并显示“未加载模块”，不为列表主动加载区块；加载后若已拆除/改绑则清理。模块摘要同时保存并同步，避免初始区块NBT覆盖GUI属性后出现空白。

右键绑定模块物品保留已有BLOCK_ENTITY_DATA，而不是只留下hostPos，避免重绑已拆卸且带库存/待交付物的机器时丢弃原数据。

### 完整器材投入

主机和矿机“器材方案”下方直接读取服务端选中variant.inputs，展示所有物品与聚合数量，最多9项开拓/4项采矿。悬停显示真实组件提示，不再按任务类型硬编码探测器/着陆舱/无人机。功率、时间仍在器材方案按钮提示中。

### EMI

新增开拓分类，替换旧矿机普通配方展示，保留组装机原配方。

- 服务器按当前查看者自身队伍进度生成配方视图，不接受客户端指定owner，不从集成服务器静态全目录读取。
- 开拓以每个天体一张EMI配方页展示；可见测绘/登陆/据点用页内标签切换，T1/T2/T3方案在同一页并列对比，明确各列是替代方案，不合并消耗。未完成前置的后续阶段、未解锁资源及其组件不发送。已完成阶段保留参考，下一阶段标明可执行。
- 采矿资源一旦测绘并通过资源可见性，就可以查阅方案；尚未登陆只提示执行前置，不再直接隐藏整页。没有可见采矿页时显示无投入/产出的引导页，保证分类可发现且不泄漏资源。
- 首次加入、天体目录或队伍进度变化、队伍作用域变化后同步，不要求先开终端。同步检查间隔20tick。
- 采矿每资源/每方案一页，只索引当前可见模式下的实际资源产量。页面明确每轮可选1至3种资源，器材投入和返回每轮一次，不把三资源所有组合展开或把三页当三次器材投入。
- 长程时间5倍、资源整数除5，据点基准，功率与跨级时间沿用执行器公式。产量为0不注册成真正正数产物。
- 任务门槛和多资源选择不能由一般合成树表达，因此禁用任务页的自动合成树，不提供伪装成可执行物品合成的转移。
- 24KB分片，单视图最多约1.056MB、8192展开页；超限记录原因并发送明确空目录，不保留旧队伍可见配方或发布半份目录。
- EMI仍为可选依赖。动态刷新桥按当前固定EMI版本验证的运行时方法反射调用，API-only编译不会硬引用内部类；没有EMI时不加载桥。

### Jade

复用一般机器Jade provider/物品图标/电压格式/进度条。太空主机与矿机没有假RecipeCrafter。

显示目标天体、当前任务阶段/状态、器材等级、所需EU/t、实际最近有效tick扣电、long进度tick及精确秒数、实际投入托管快照、完整冻结产物，另列剩余待交付或待退款。

服务器每次请求重新检查当前查看者作用域与机器固定owner；外队/无owner/损坏owner/任务owner不符不发送任务数据。目标名称遵从可见性，不同步内部任务ID或UUID。未开始扣电、暂停、堵输出和退款显示实际耗电0。一般机器原有配方与发电显示路径保持不变。

### 视觉反馈

真实服务端任务发射、完成、退款事件产生终端提示和扩散环。星图显示当前任务目标括号、地球出发的简化转移轨道，测绘运行时扫描环；转移弧以地球公转切线离轨、按目标公转切线入轨，月球入轨使用其地球父节点。轨道几何在星图坐标计算，缩放/拖动不会把起点改成窗口角落；这是轻量机动示意，不是开普勒轨道求解。跨星系页不虚构坐标连线，明确显示地球位于另一星系。浏览其他天体不改变真实任务目标，也不因点击天体伪造扫描完成。

机器附近32格内的本队玩家收到轻量粒子/声音；运行粒子仅在足额扣电时发生，采矿的同类事件按40tick限流，避免高频自动采矿刷屏。效果只读，不消费材料、不推进阶段、不修改经济。事件/最近扣电为瞬态，不写入任务存档、不在重启后补播旧事件。普通公开区块NBT不包含这些私有任务事件。

## 验收步骤

1. 主机与模块绑定后放置但不放任务材料、不完成结构，主机列表应在2秒内显示矿机/组装机；重开GUI、重启、模块区块卸载再加载后仍正确。破坏或重新绑定后旧主机清理条目。
2. 选择月球据点方案，器材栏应同时显示数据包配置的着陆舱与据点核心，数量和组件正确；其他自定义投入不被默认航天器覆盖。
3. 不开机器终端直接查看EMI：未测绘只有可见测绘方案与采矿引导页；测绘后资源可见时出现采矿页，未登陆时明确提示执行前置；完成登陆/据点自动更新。同一天体开拓仅一张配方页，内含T1/T2/T3开销对比；切换阶段不拆成额外配方。切换队伍/服务器不保留旧可见配方。EMI不存在时正常游玩。
4. Jade查看运行主机与矿机，确认目标是任务冻结目标而不是新编辑的下轮选择，投入/产物与实际任务一致。断电、红石暂停、手动暂停、输出堵塞、reload退款分别显示状态和0实际耗电，仍保留所需方案功率。
5. 外队玩家不能经Jade读取任务私有目标与物品。一般机器Jade信息仍正常。
6. 发射时看地球起点和简化转移弧，月球/火星抵达方向应沿各自公转切线；缩放和拖动不能把起点吸附窗口角落。跨星系显示地球来源，不画错误连线。真实测绘运行看扫描，完成及退款看提示与扩散环；切换浏览目标不应挪动任务目标。粒子/声音随任务实际执行，不应在缺电时继续，快速采矿不会无限刷音效。
7. 核对不同GUI缩放、英文长文本、长资源名称、最高9个投入图标的悬停与裁剪。未成型灰层不盖住玩家库存及原生配置页。
